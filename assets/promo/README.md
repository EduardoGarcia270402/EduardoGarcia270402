# Terminal profile promo

`eduardo-terminal.gif` is the animated header used by the profile README. It is
1760 × 880, contains 386 rendered frames, lasts approximately 38 seconds, and
uses the same terminal-animation structure as the referenced `guilyx/guilyx`
profile.

`eduardo-terminal.webp` contains the same sequence in full colour. Both files
are generated by `generate.py` using Pillow and a fixed random seed.

```bash
pip install pillow
python assets/promo/generate.py
```

The animation contains:

- CRT power-on and terminal handshake
- Personal identity card
- Full-stack product-build tree
- AI-agent orchestration graph
- Technology learning trajectory
- GitHub and LinkedIn sign-off

The content intentionally excludes employers, clients, and job history.
