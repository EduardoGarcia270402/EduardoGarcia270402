## Selected experience

### SERCOP Quotation Automation · PINPREXAT

Full-stack platform that extracts procurement data, generates company-validated PDF quotations, and automates the post-signature workflow in SERCOP.

- Built with **Next.js 16, React 19, TypeScript, Python, Flask, PostgreSQL, SQLAlchemy, and Prisma**.
- Automated login, unit-price entry, and document uploads using **Playwright**.
- Integrated a **Telegram bot** to receive links, download attachments, and parse terms of reference and specifications.

### Corporate Asset Services App · @ctivos+

Cross-platform mobile application for registering, updating, searching, and reporting on physical company assets.

- Developed the mobile experience with **Flutter** and an **MVC architecture**.
- Implemented business logic and REST services with **Supabase** as the backend platform.
- Modeled operational data in **PostgreSQL**.

### Martina AI Chatbot · Firmas Electrónicas EC / SaciERP

Intelligent customer-service chatbot designed to automate support for concurrent users on an electronic-signature platform.

- Implemented a **RAG architecture** over structured and unstructured knowledge.
- Orchestrated ingestion, retrieval, and response workflows with **n8n**.
- Integrated **LLMs, AI agents, semantic search, vector databases, PostgreSQL, and AWS**.

### Integrated Web Platform · Seguridad Electrónica 593

High-conversion business website backed by a modular and scalable architecture.

- Built a dynamic, responsive frontend with **Angular**.
- Developed REST APIs and business logic with **Node.js and JavaScript**.
- Designed relational models in **PostgreSQL** and deployed the solution on **AWS**.
